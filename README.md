# Flora Deck v7.0 Power Suite

A browser-based presentation editor focused on replacing the core PowerPoint workflow while keeping the soft Flora UI.

## Power Suite highlights
- Flora/PowerPoint-style ribbon, slide thumbnails, canvas, Design sidebar, notes strip and status bar
- Slide layouts, themes, page sizes, slide sections, slide numbers, master/theme editor and design ideas
- Text formatting, shapes, media, tables, charts, icons, stickers and exact scalable custom Window sticker
- Layers, grouping, align/distribute, grid, guides, ruler, multi-select, context menu and keyboard shortcuts
- Transitions including Morph, fade, push, wipe, split, reveal, zoom, flip and cube
- Cute entrance/emphasis animations including Soft Pop, Float, Doodle, Wiggle, Sparkle and Paper
- Story Rail with custom text/image/SVG symbols, active ring, Morph behavior, refresh and delete
- Presenter mode, speaker notes, timer, laser, touch swipe, autoplay, rehearse timings and screen recording
- PPTX import (basic editable extraction) and editable PPTX export for common text/shapes/images/tables/charts
- PNG/JPG, PDF/print, JSON and standalone HTML export paths retained from the existing editor
- Desktop/tablet/mobile responsive editing and automatic fit on small screens
